# מה הפלט? · Python

אתר תרגול בעברית לשאלות "מה ידפיס הקוד?" בפייתון. 234 שאלות עם 4 אפשרויות בכל אחת, והסבר מלא אחרי כל תשובה: איך מגיעים לתשובה, מה הפלט בפועל, ולמה כל אחת מהאפשרויות נכונה או לא.

A Hebrew (RTL) practice site for "what does this Python code print?" questions, with a full explanation for every option.

## נושאים

משתנים · תנאים · לולאות · רשימות · tuple ו-set · מילונים · מחרוזות · פונקציות · ניהול שגיאות · איזו חריגה? · קבצים · מחלקות · פולימורפיזם · גנרטורים · טריקים · באגים ושגיאות

## תכונות

- כל תשובה נכונה נבדקה בהרצה אמיתית של Python 3.13 (`questions.py` מריץ כל שאלה ומשווה לפלט).
- שאלות על קוד שזורק שגיאה (TypeError, KeyError, UnboundLocalError...) ועל באגים שקטים.
- ההתקדמות נשמרת בדפדפן, וכשחוזרים ממשיכים מאותה שאלה.
- סינון לפי נושא, מפת שאלות, מקשי קיצור (1–4 לבחירה, חצים למעבר).

## הרצה

פשוט לפתוח את `index.html` בדפדפן. אין צורך בשרת.

## הוספת שאלות

1. להוסיף קריאה ל-`q(...)` ב-`questions.py` (קטגוריה, קוד, 4 אפשרויות, אינדקס התשובה, הסבר, והסבר לכל אפשרות).
2. להריץ:

```bash
python build.py
```

הסקריפט מריץ את כל השאלות, עוצר אם יש תשובה שלא תואמת לפלט האמיתי, ובונה מחדש את `index.html`.
